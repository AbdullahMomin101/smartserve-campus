# Resume entry: Smart Canteen

## Recommended project listing

**Smart Canteen — AI & IoT Food Waste Prediction Prototype** | Engineering Project | HTML, CSS, JavaScript, Chart.js, LocalStorage

- Built a responsive, static web prototype that connects **five simulated IoT sensor streams** to live canteen monitoring, threshold alerts, food operations, and waste analytics.
- Implemented an explainable demand-forecasting algorithm using **seven inputs**: expected attendance, current attendance, historical consumption, prior waste, weekday, event status, and weather; displayed predicted demand, preparation quantity, consumption, and expected waste.
- Developed persistent food-item CRUD, simulation controls, filtered Chart.js analytics, recommendations, dark/light theme, and a presentation-mode walkthrough using browser LocalStorage.
- Prepared the application for static deployment on GitHub Pages, Netlify, or Vercel; documented the path to replace simulated readings with calibrated ESP32 sensor data.

## Portfolio README summary

Smart Canteen is a browser-based engineering prototype for canteen demand planning. It simulates five IoT data streams and uses an explainable browser algorithm to estimate food demand and recommended preparation quantities. The static application includes food operations, alerts, analytics, and presentation mode. Sensor data is simulated; the forecasting calculation is not a trained ML model.
